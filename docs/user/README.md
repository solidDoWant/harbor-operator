# harbor-operator for chart authors

For: people who write the Kubernetes resources for a project, for example in a Helm chart that sets up CI. You know Kubernetes YAML and Helm.

harbor-operator is in early development. These pages are not written yet. They will tell you how to:

- make a Harbor project with its settings and storage quota;
- make a robot account that CI can push with, and use its Secret in a pipeline;
- read the status of each resource, and what each reason means.

Until then, read [`SPEC.md`](../../SPEC.md).
